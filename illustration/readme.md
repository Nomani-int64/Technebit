Technebit-illustration: just images
======
*锝比特-插画：就一堆图像*

*by Nomani (alias/别名: Nomani_int64 / Nomani-int64)*

Images of Technebit. `.kra` files are editable files for the drawing software [Krita](https://invent.kde.org/graphics/krita), and for those
not wanting another software on their device, an exported `.psd` version is also provided. I'm not a
[Adobe Photoshop](https://www.adobe.com/products/photoshop.html) user, so **the validity of `.psd` files is not guaranteed.**

锝比特的帅照。`.kra` 文件是 [Krita](https://invent.kde.org/graphics/krita) 的可编辑文件，如果不想再安装一个软件，也可以使用导出的 `.psd` 文件。我自己不用
[Adobe Photoshop](https://www.adobe.com/products/photoshop.html)，所以**不保证 `.psd` 文件可以正常使用**。
